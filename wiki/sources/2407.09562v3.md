## Problem

Deploy a real-time object detector for chicken health monitoring on a Sony IMX500 CMOS sensor — an ultra-constrained edge AI device with only 8MB memory. Standard detectors (YOLO variants, ResNet-based FCOS) are too large; overly aggressive pruning degrades accuracy beyond acceptable thresholds.

## Method

**FCOS-Lite**: Compact anchor-free object detector based on FCOS with MobileNet backbone for minimal parameter count.

**Two custom loss components**:
- **Gradient weighting loss** for classification: weights loss contributions by gradient magnitude to focus training on hard examples
- **CIOU (Complete Intersection over Union) loss** for localization: smoother localization objective than standard IoU

**Knowledge Distillation**: Teacher = full-size FCOS (ResNet backbone); Student = FCOS-Lite (MobileNet backbone). KD transfers feature-level and output-level information without increasing student inference cost.

**INT8 quantization** for deployment on IMX500: the final model is quantized to INT8 for edge deployment on the CMOS sensor.

## Results

| Metric | FCOS-Lite + KD + INT8 |
|--------|----------------------|
| mAP | 95.1% |
| F1-score | 94.2% |
| Inference speed | >20 FPS on IMX500 CMOS sensor |
| Memory constraint | 8MB (IMX500 on-chip memory) |

Outperforms other SOTA lightweight detectors on the task. Published in *Computers and Electronics in Agriculture* (2024).

## Significance

Confirms that KD + INT8 quantization compose effectively for ultra-constrained edge AI deployment (8MB memory). Key evidence: KD enables a MobileNet-based model to approach ResNet accuracy without increasing inference cost; INT8 quantization then fits the model within 8MB without prohibitive accuracy loss. The Sony IMX500 is a novel class of edge device — a CMOS image sensor with embedded AI inference, eliminating the need for a separate MCU.

For HaLViT: the IMX500's 8MB constraint is an order of magnitude tighter than typical edge AI targets. HaLViT at 11M–22M params (44–88MB in FP32) would need all three: weight sharing (built in), quantization (INT8 or lower), and possibly KD to fit within such constraints. This paper confirms INT8 + KD as a viable pipeline for sub-10MB edge deployment.
