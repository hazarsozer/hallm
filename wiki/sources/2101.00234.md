## Problem

ALBERT-style all-layer cross-layer sharing works for BERT (discriminative pretraining) but catastrophically fails for generative/seq2seq Transformers: naively sharing all layers collapses WMT'14 EN-DE BLEU from 27.3 to 14.3 with 24M parameters. Even increasing the model dimension (41M, BLEU 22.0) does not recover performance. The bottleneck is that **generative tasks require token-level representations** — the input and output layers must learn task-specific projections that cannot be shared without severe degradation.

Additionally, standard Transformer embedding layers can account for up to 25% of total parameter count, yet this cost is rarely reduced in seq2seq settings.

## Method

The Subformer combines two independent parameter reduction techniques.

### 1. SAFE: Self-Attentive Factorized Embeddings

Instead of a standard embedding E ∈ ℝ^{V×d_m} (V×d_m params), SAFE uses:
1. Small embedding matrix E ∈ ℝ^{V×d_e} with d_e ≪ d_m
2. A small self-attention sub-layer + FFN module to project d_e → d_m contextually

**Parameter count**:
```
Standard: V × d_m
SAFE:      V × d_e + 5d_e² + d_e × d_m
```
For d_e=256, d_m=512, V=32K: standard ≈ 16.4M, SAFE ≈ 8.3M + 0.33M + 0.13M ≈ 8.8M.

Key insight: standard embeddings are non-contextual token → vector lookups; even a small self-attention layer on top makes them contextual, which is more expressive than a linear projection at the same parameter count.

**Ablation (Table 1, Transformer-base, WMT'14 EN-DE, INT3-g128)**:
| Config | Params | BLEU |
|--------|--------|------|
| Standard (d_e=d_m=512) | 65M | 27.3 |
| Linear projection d_e=256 | 54M | 27.1 |
| Linear projection d_e=128 | 48M | 26.0 |
| SAFE d_e=256 | 54M | **27.7** |
| SAFE d_e=128 | 48M | 26.6 |

SAFE (d_e=256) matches the standard Transformer at the same parameter count while reducing embedding parameters, and achieves **+0.4 BLEU** over linear projection at d_e=256.

### 2. Sandwich-Style Parameter Sharing

**Ablation of sharing strategies (Table 2, WMT'14 EN-DE)**:
| Strategy | Params | BLEU |
|----------|--------|------|
| All-Shared | 24M | 14.3 |
| All-Shared (d_m=768) | 41M | 22.0 |
| All-Shared (Independent FFN) | 27M | 22.4 |
| All-Shared (except last) | 31M | 23.2 |
| Every 2 layers shared | 38M | 27.2 |
| **Sandwich** (share middle only) | **38M** | **27.3** |
| Sandwich, L=8 (deeper) | 38M | **27.7** |
| Transformer-base | 65M | 27.3 |

**Sandwich rule**: Share only the **middle** layers (2 ≤ l ≤ L−1); leave layers 1 (bottom model layer) and L (top model layer) with independent weights.

**Why it works**: In generative models, the first layer processes raw token embeddings and must learn task-specific representations of input tokens. The last layer must project to vocabulary space (output distribution). Both roles are fundamentally different from the shared central computation — they cannot be tied without a significant accuracy penalty. The "All-Shared (except last)" baseline (+0.9 over all-shared) confirms that freeing just the last layer helps, but freeing both ends (Sandwich) is necessary to match the baseline.

**Sandwich Module architecture**:
- Model dimension d_m (layers 1 and L)
- Sandwich dimension d_s (shared middle layers) — can be larger than d_m
- Projection layers (linear, learnable) connect d_m ↔ d_s
- The d_s > d_m option allows wider shared layers, increasing capacity without adding independent parameters

**Combined Subformer architecture** (encoder + decoder):
- Embedding layer: SAFE (d_e → d_m via small self-attention)
- Layer 1: model layer (independent), d_m
- Layers 2 to L-1: Sandwich module (shared), d_s dimension
- Layer L: model layer (independent), d_m
- Output projection: tied to decoder input embedding (Press & Wolf 2017)

## Results

### Machine Translation — WMT'14 EN-DE (Tables 3 & 4)

**Base-scale models**:
| Model | Params | BLEU |
|-------|--------|------|
| Transformer-base (orig) | 65M | 27.3 |
| Sandwich-base (sharing only) | 38M | 27.3 |
| Subformer-small (SAFE+Sandwich) | **38M** | **27.7** |
| Subformer-base | **52M** | **28.5** |
| Subformer-mid | 63M | ~28.6 (≈ Transformer-big at 210M) |

Subformer-mid (63M) performs similarly to Transformer-big (210M) — **70% parameter reduction**.

**Large-scale models**:
| Model | Params | BLEU |
|-------|--------|------|
| Transformer-big (orig) | 213M | 28.4 |
| Sandwich-big | 122M | 28.6 |
| **Subformer-large** | **197M** | **29.3** |

Subformer-large achieves **+0.9 BLEU** over Transformer-big with 13M fewer parameters.

| Model | Params | Speed |

Training time: 10-30% faster; convergence: 65% fewer iterations. Inference can be slightly slower when d_s ≫ d_m due to wider sandwich layers.

## Significance

- **Resolves the ALBERT-for-generation problem**: proves conclusively why all-layer sharing fails for seq2seq (first/last layers must be independent), and provides a simple fix: Sandwich sharing
- **Sandwich insight is general**: any Transformer-based generative model can apply Sandwich-style sharing to its middle layers with minimal architectural modification
- **SAFE is orthogonal**: embedding parameter reduction works independently and compounds with Sandwich sharing
- **HaLViT composability (thesis relevance)**: Subformer's cross-layer Sandwich sharing and HaLViT's intra-layer W+Wᵀ sharing operate on **orthogonal axes** — the former shares weight matrices across depth, the latter shares a matrix with its own transpose within a single layer. In principle, a model could apply both simultaneously: HaLViT's W+Wᵀ within each layer + Subformer's Sandwich sharing across layers. The Sandwich constraint (first/last independent) would apply if extending HaLViT's sharing across depth: the first and last ViT blocks should keep their own W matrices unshared across layers. This is an unexplored composition.
- **Confirms overparameterization in generative models**: Sandwich-mid (63M) ≈ Transformer-big (210M); compression ratio of ~3.3× with no accuracy loss indicates the central layers of a standard Transformer are heavily redundant.

## Contradicts / Supports

- **Supports** [[sources/1909.11942]] (ALBERT): cross-layer sharing works; but ALBERT's all-layer approach is specific to discriminative pretraining. Subformer shows the strategy must be adapted for generation — the Sandwich variant is the correct generative analogue of ALBERT's all-sharing
- **Supports** [[sources/halvit]]: the overparameterization finding aligns with HaLViT's motivation — middle Transformer layers are redundant; both papers exploit this in different ways (cross-layer vs intra-layer)
- **Relevant to** [[sources/2410.03765]] (Basis Sharing): both perform cross-layer sharing, but Basis Sharing uses SVD-based post-training calibration, while Subformer uses architectural sharing trained from scratch. The Sandwich structure could potentially be applied to Basis Sharing (share the basis only for middle layer groups)
