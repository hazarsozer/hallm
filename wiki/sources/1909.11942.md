## Problem

Scaling BERT by increasing hidden size H hits GPU/TPU memory limits fast — the embedding matrix alone is V×H (vocabulary × hidden), which grows quadratically. More layers means more parameters linearly with depth. Both obstacles prevent scaling to larger, more capable models.

## Method

Three contributions, not one. The first two are parameter reduction; the third is a training objective improvement.

### 1. Factorized Embedding Parameterization

BERT ties vocabulary embedding size E to hidden size H (E ≡ H). This is wasteful: embeddings are context-independent (one vector per token), but hidden states are context-dependent. They don't need to be the same size.

ALBERT decouples them: project one-hot vectors first into a low-dimensional embedding space E, then into the hidden space H.

```
Embedding parameters: V×H → V×E + E×H
Reduction when H >> E: e.g. V=30k, H=768, E=128 → from 23M to 4.2M (5.5×)
```

This makes growing H cheap — adding hidden capacity no longer bloats the vocabulary embedding. **This is the enabling companion to cross-layer sharing**, not a standalone technique.

### 2. Cross-Layer Parameter Sharing

Share all parameters across all transformer layers (default). The same weight matrices are used for every layer — attention and FFN alike.

Variants tested (Table 4):
- **all-shared** (ALBERT default): attention + FFN shared across all L layers
- **shared-attention**: only attention weights shared
- **shared-FFN**: only FFN weights shared
- **not-shared**: standard BERT (baseline)

**Critical ablation finding (Table 4, E=128)**:

| Strategy | Params | Avg |
|----------|--------|-----|
| not-shared | 89M | 81.6 |
| shared-attention | 64M | 81.7 (+0.1!) |
| shared-FFN | 38M | 80.2 (−1.4) |
| all-shared | 12M | 80.1 (−1.5) |

Sharing attention costs almost nothing. Sharing FFN is where the accuracy drop comes from. Most of the parameter savings (from 89M → 12M) incur only 1.5 Avg points loss.

**Layer dynamics**: Figure 1 shows ALBERT's layers have oscillating L2 distances and cosine similarities rather than converging (unlike BERT). The shared weight solution space is fundamentally different — embeddings don't converge to a fixed point but oscillate between meaningful representations. This is stable behavior, not a failure mode.

### 3. Sentence Order Prediction (SOP)

Replaces BERT's Next Sentence Prediction (NSP) loss. NSP conflates topic prediction (easy) with coherence prediction (hard). SOP uses two consecutive segments from the same document — either in correct order (positive) or swapped (negative). This forces coherence modeling.

**SOP vs NSP** (Table 5):
- None: downstream Avg 79.0
- NSP: downstream Avg 79.2 (+0.2 — barely better than nothing)
- SOP: downstream Avg 80.1 (+1.1 over NSP)

NSP essentially fails at SOP (52% accuracy = random), while SOP solves NSP reasonably (79%). SOP is strictly better.

## Results

### GLUE Dev Set (125k steps, Table 2)

| Model | Params | Avg | Speedup |
|-------|--------|-----|---------|
| BERT-large | 334M | 85.2 | 1.0× |
| ALBERT-base | 12M | 80.1 | 5.6× faster |
| ALBERT-large | 18M | 82.4 | 1.7× faster |
| ALBERT-xlarge | 60M | 85.5 | 0.6× (slower) |
| ALBERT-xxlarge | 235M | 88.7 | 0.3× (slower) |

ALBERT-xxlarge beats BERT-large by **+3.5 Avg** with 30% fewer parameters.

### GLUE Leaderboard (Ensemble, Table 9)

ALBERT ensemble: **89.4 Avg** — state of the art at submission time, beating RoBERTa (88.5) and XLNet (88.4).

### Same Training Time Comparison (Table 6)

BERT-large (400k steps, 34h): Avg 87.2  
ALBERT-xxlarge (125k steps, 32h): **Avg 88.7** (+1.5)

Given equal wall-clock time, ALBERT wins.

## Significance

ALBERT is the **canonical cross-layer weight sharing paper** in NLP and the most direct conceptual predecessor to HaLViT's sharing scheme — with critical differences:

| Dimension | ALBERT | HaLViT |
|-----------|--------|--------|
| Sharing axis | Across layers (depth) | Within layer (width: W vs Wᵀ) |
| Mechanism | Same weight matrix reused across all L layers | W and Wᵀ as two independent transforms within one layer |
| Companion technique needed | Yes — embedding factorization | No |
| Parameter reduction | Up to 18× vs BERT-large | ~2× per layer |
| Accuracy cost | ~1.5 Avg points (all-shared vs not-shared) | ~1–2% Top-1 ImageNet |
| Domain | NLP (BERT-style pretraining) | Vision (ViT, ResNet) |
| Layer dynamics | Oscillating (does not converge) | Not studied |

**The two mechanisms are complementary, not competing**: ALBERT prevents parameters growing with depth; HaLViT prevents them growing with width. Stacking ALBERT-style cross-layer sharing on top of HaLViT-style intra-layer sharing would be extreme compression — a thesis-worthy experiment.

## Open Questions Raised

- Does HaLViT's layer dynamics (L2 distance, cosine similarity between layer I/O) look like ALBERT's oscillating pattern or something different?
- ALBERT shows FFN sharing is more costly than attention sharing. Does HaLViT's FFN sharing (W→Wᵀ within one layer) follow the same trend?
- Can ALBERT's embedding factorization be applied to HaLViT's patch embedding to enable larger hidden dimensions without proportionally larger embedding matrices?
- The optimal ALBERT embedding size is E=128 regardless of H. Is there an analogous optimal sharing rank for HaLViT?

## Contradicts / Supports

- Supports [[sources/halvit]]: both show weight sharing achieves significant parameter reduction with recoverable accuracy loss
- Nuances [[concepts/weight-sharing]]: the two sharing types (cross-layer vs intra-layer) have different accuracy cost profiles — ALBERT's ablation gives the field's clearest decomposition of this
