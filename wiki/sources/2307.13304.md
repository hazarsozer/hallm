## Problem

All existing LLM quantization methods produce unacceptable results at 2 bits per weight. The structural cause: weight matrices W and their Hessians H are **coherent** — weights have uneven magnitude (outliers) and the directions requiring accurate rounding are aligned with coordinate axes. Coherence means rounding errors are large and correlated, because the quantization grid is coarsely aligned with the weight distribution's natural axes.

Additionally, no theoretical guarantees existed for any LLM-scale PTQ algorithm. GPTQ's column-sequential rounding procedure lacked formal analysis of its optimality or error bounds.

## Method

QuIP (Quantization with Incoherence Processing) consists of two steps.

### Step 1: Adaptive Rounding via LDLQ

QuIP minimizes the quadratic proxy objective for quantization error:

```
ℓ(Ŵ) = tr((Ŵ − W)H(Ŵ − W)ᵀ)   (Eq. 1)
```

where H = E_x[xxᵀ] is the second-moment Hessian proxy (same construction as GPTQ). The optimal column-sequential rounding procedure within the class of linear-feedback methods is **LDLQ** — derived via LDL factorization of H:

```
H = (Û + I)D(Û + I)ᵀ   (LDL decomposition, Eq. 4)
```

where D is non-negative diagonal and Û is strictly upper unit triangular. The LDLQ update rule:

```
Ŵ_k = Q(W_k + (W_{1:(k-1)} − Ŵ_{1:(k-1)}) a_k)
```

where a_k are the columns of Û. This feeds back quantization error from previously-rounded columns to correct current rounding decisions. The final quantized matrix satisfies:

```
Ŵ = Q(W + (W − Ŵ)U)   (Eq. 2)
```

**Theorem 1 (Optimality)**: LDLQ is worst-case and average-case optimal among all rounding methods in the class Eq. (2), for all positive semi-definite H:

```
m/4 · tr(D) = L_worst(LDLQ, H) ≤ L_worst(A, H)   for any A in the class
m/c · tr(D) = L_avg(LDLQ, H) ≤ L_avg(A, H)       (c=12 nearest, c=6 stochastic)
```

**Theorem 6 (GPTQ as special case)**: OPTQ (GPTQ) falls within the class of Eq. (2) and is equivalent to LDLQ — providing the first theoretical analysis for GPTQ. LDLQ is more efficient (one Cholesky decomposition vs. two matrix inversions in OPTQ).

### Step 2: Incoherence Processing

Without incoherence, the theoretical bound from Theorem 1 involves tr(D) from H's LDL decomposition — which is large when H is coherent (diagonal-dominant or nearly diagonal). Incoherence processing makes both W and H incoherent by pre- and post-multiplying by random orthogonal matrices:

**Pre-processing (Algorithm 1)**:
```
1. Sample random orthogonal U ∈ ℝ^{m×m}, V ∈ ℝ^{n×n}  (Kronecker products)
2. H ← H + α·mean(diag(H))·I   (from GPTQ, for numerical stability)
3. D̃ ← ⁴√(diag(H)/diag(WᵀW))  (diagonal rescaling)
4. W ← W·D̃; H ← D̃⁻¹HD̃⁻¹       (diagonal rescaling)
5. W ← UWVᵀ; H ← VHVᵀ          (incoherence rotation)
6. s ← ρ·||W||_F/√mn; W ← ½(W/s + 1)   (rescale to quantization range)
7. W ← clamp(W·(2^b−1), 0, 2^b−1)
```

**Post-processing (Algorithm 2)**:
```
1. Sample same U, V (from same random seed)
2. W ← s·((W/(2^b−1))·2−1)   (reverse scaling)
3. W ← UᵀWV; H ← VᵀHV        (reverse rotation)
4. W ← W·D̃⁻¹                 (reverse diagonal rescaling)
```

**Efficient implementation**: Rather than materializing full n×n random orthogonal matrices (prohibitive), QuIP uses Kronecker products. For n = p·q: U = U_L ⊗ U_R where U_L is p×p, U_R is q×q orthogonal. Multiplication takes O(n(p+q)) = o(n²) operations.

**Lemma 5 (incoherence guarantee)**: With k=2 Kronecker factors, VHVᵀ is μ_H-incoherent with probability ≥ 1−δ where μ_H = Õ(1) — independent of matrix size. Similarly W is μ_W-incoherent.

**Why incoherence helps (Lemma 2)**: For μ-incoherent H:
```
tr(D) ≤ μ²/n · tr(H^{1/2})²
```
This bound is tighter by a factor of μ²k/n vs. the incoherent baseline (Theorem 4 shows improvement requires incoherence — without it, LDLQ cannot be proven better than nearest rounding using only spectral information of H).

**Full QuIP (Algorithm 3)**:
```
W, H, s, D̃ ← Algorithm 1(b, H, W, ρ, α)   (pre-processing)
H ← (Û+I)D(Û+I)^{-1}                        (LDL decomposition)
for k = 1,...,n: Ŵ_k ← clamp(Q(W_k + (W−Ŵ)Û_k), 0, 2^b−1)   (LDLQ)
Ŵ ← Algorithm 2(b, H, Ŵ, s, D̃)            (post-processing)
```

## Results

### OPT family — WikiText2 PPL (2-bit and 3-bit)

| Model | FP16 | GPTQ 3-bit | QuIP 3-bit | GPTQ 2-bit | QuIP 2-bit |
|-------|------|-----------|-----------|-----------|-----------|
| OPT-125M | 27.65 | 32.64 | **30.13** | 1.3e5 | **77.22** |
| OPT-1.3B | 14.63 | 16.99 | **15.62** | 4.3e3 | **23.88** |
| OPT-2.7B | 12.47 | 13.94 | **13.04** | 245.6 | **17.62** |
| OPT-6.7B | 10.86 | 11.72 | **11.38** | 97.4 | **13.26** |
| OPT-13B | 10.13 | 10.55 | **10.35** | 28.3 | **12.08** |
| OPT-30B | 9.56 | 9.93 | **9.84** | 15.1 | **10.93** |
| OPT-66B | 9.34 | 9.49 | **9.41** | 11.7 | **9.96** |

At **2-bit**: QuIP achieves the first viable results — prior methods diverge (1.3e5 PPL). At 3-bit: QuIP consistently outperforms GPTQ. The 2-bit vs 4-bit quality gap shrinks as model size increases.

### Llama-2-70B — WikiText2 PPL

| Method | 2-bit | 3-bit | 4-bit |
|--------|-------|-------|-------|
| GPTQ | 40.8 | 4.40 | 3.53 |
| **QuIP** | **4.58** | **3.99** | **3.44** |

At 70B scale, QuIP at 2-bit (PPL 4.58) approaches GPTQ at 4-bit (PPL 3.53) — one full bit-width reduction with modest accuracy cost.

- Max |W_{ij}| before incoherence: ~0.35; after: scattered around 0.05–0.10 (weight magnitudes equalized)
- Max |Q_{ij}| (eigenvectors of H) before: ~0.8; after: ~0.15–0.20 (Hessian directions equalized)
- Both distributions tighten around their means → incoherence achieved

## Significance

- **First viable 2-bit LLM quantization**: cracks the 2-bit barrier that all previous methods fail to cross
- **First theoretical analysis for LLM-scale PTQ**: Theorem 1 proves LDLQ is optimal within the class; Theorem 6 proves GPTQ is a special case; Theorem 4 proves incoherence is *necessary* (without it, no spectral bound can separate LDLQ from nearest rounding)
- **Unifies prior outlier-suppression methods**: LLM.int8(), SmoothQuant, SpQR, SqueezeLLM are all heuristic approximations of the same incoherence principle — they suppress outliers locally. QuIP applies incoherence globally via random rotations with theoretical guarantees
- **For HaLViT**: at 11M–22M params, 2-bit is aspirational — QuIP's contribution is more theoretical for HaLViT than practical. However, the incoherence rotation applied to shared W+Wᵀ raises a specific structural question: the same orthogonal matrices U, V are applied to W (pre: W←UWVᵀ; post: Ŵ←UᵀŴV). For the transposed use, the effective transformation is Wᵀ←VWᵀUᵀ and Ŵᵀ←VŴᵀU. The rotation matrices swap roles — V incoherences the "row" dimension of Wᵀ, and U incoherences its "column" dimension. Whether a single pair (U,V) simultaneously incoherences both the W→x and Wᵀ→x' contexts depends on whether the activation statistics X and X' are both made approximately uniform by the rotation. For independent random X, X', this holds; for the correlated activations of a trained ViT, it requires empirical verification.
