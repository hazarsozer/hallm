## Problem

SVD-based LLM compression treats each layer independently — no information is shared across layers despite weight matrices in different layers exhibiting strong structural similarity. Prior cross-layer sharing (ALBERT-style, Dynamic Tying) requires training from scratch and forces identical weights, degrading performance. No post-training method exploits cross-layer structure for better compression.

## Method

Basis Sharing decomposes weight matrices across n layers into a **shared basis B** and **layer-unique coefficients C^(i)**:

```
W^(i) ≈ B · C^(i)     (each layer shares B, keeps its own C)
```

**Step-by-step:**

1. **Concatenate horizontally**: Stack weight matrices from n layers into W ∈ ℝ^(d1 × nd2)
2. **Activation-aware scaling**: Compute S where S(S)ᵀ = cholesky((X_concat)ᵀ X_concat), using 256 WikiText-2 samples (2048 tokens each). X_concat is the vertical stack of inputs to all n layers.
3. **SVD on scaled matrix**: Decompose SW ≈ U'_k Σ'_k V'_k^T, keeping top-k singular values
4. **Recover weight basis**: Final adjusted basis B'' = S⁻¹ U'_k Σ'_k  
5. **Per-layer coefficients**: C^(i) = V'_k^T columns corresponding to layer i

Full approximation (Eq. 3 in paper):
```
W ≈ S⁻¹ U'_k Σ'_k V'_k^T = B'' · C'
```

**Which weights can share (empirical criterion):**  
Select weight types where joint Frobenius loss < sum of individual losses. The paper evaluates pairwise basis sharing across all 32×32 layer combinations via a symmetric heatmap (Figure 4).

| Weight type | Supports cross-layer sharing? | Reason |
|-------------|-------------------------------|--------|
| W_K | Yes | Adjacent layers have similar basis structure |
| W_Q | Yes | Adjacent layers have similar basis structure |
| W_V | Yes | Adjacent layers have similar basis structure |
| W_Up | Yes (LLaMA FFN gate up-projection) | Shared basis reduces loss |
| W_Gate | Yes (LLaMA gating mechanism) | Shared basis reduces loss |
| W_Down | **No** | Projects high→low dim; concatenating increases rank; joint SVD strictly worse than individual |
| W_O | **No** | Same issue as W_Down |

**Layer grouping strategy:**  
Group consecutive layers: (1,2), (3,4), … from first to last. Optimal group size depends on compression ratio:
- Compression < 30%: groups of 4–5 adjacent layers
- Compression ≥ 30%: pairs of 2 adjacent layers

## Significance

- **First post-training cross-layer SVD method** that consistently outperforms per-layer SVD at all compression ratios — closes the gap that naive cross-layer sharing (ALBERT) cannot.
- **No training required** — entire compression pipeline uses 256 calibration samples; optional LoRA fine-tuning recovers further.
- **Memory-efficient at scale**: FWSVD requires gradients (OOM at 13B+); Basis Sharing is training-free.
- **Throughput gains are real**: Compression → fewer weights → less memory bandwidth → 1.57× tokens/sec at 50%.
- **Direct relevance to HaLViT**: HaLViT applies intra-layer W+Wᵀ sharing on ViT. Basis Sharing shows cross-layer basis sharing works on LLMs without training. The two approaches are complementary and could compose: apply Basis Sharing to compress HaLViT's shared weights across depth.
- **Kills Dynamic Tying as a baseline**: Basis Sharing on a 3× smaller model, in seconds, beats Dynamic Tying trained for hours on a 3× larger model. Training-from-scratch sharing is obsolete for compression.

## Contradicts / Supports

- **Contradicts** [[sources/1909.11942]] (ALBERT) on optimal sharing strategy: ALBERT uses identical weight matrices across layers; Basis Sharing shows that shared basis + unique coefficients strictly outperforms identical-weight sharing for post-training compression — the individuality of coefficients matters.
- **Supports** [[sources/halvit]] on composability promise: both methods are post-training / training-efficient; their combination (intra-layer W+Wᵀ + cross-layer basis) is feasible without retraining.
- **Extends** prior SVD work (ASVD, SVD-LLM) by demonstrating that cross-layer correlation is an underexploited dimension of weight compression.
